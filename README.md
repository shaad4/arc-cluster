# ARC

A self-hosted distributed computing cluster monitoring
and management dashboard.

## Infrastructure

- 5 compute nodes
- 20 vCPUs
- ~39 GiB aggregate RAM
- Ray distributed computing
- Tailscale private networking

## Tech Stack

- FastAPI
- React
- Tailwind CSS
- Ray
- Python

## Features

- Real-time cluster monitoring
- Node resource metrics
- Ray worker management
- Cluster health monitoring
- Distributed job monitoring
